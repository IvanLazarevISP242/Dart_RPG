### ответы на вопросы

1. **Что такое абстрактный класс? Почему нельзя написать Character() напрямую?**

• Абстрактный класс — это класс-шаблон, предназначенный исключительно для наследования другими классами, который нельзя инстанцировать напрямую.
• Написать Character() нельзя, так как этот класс описывает общую концепцию персонажа, но сам по себе не является конкретным игровым существом (непонятно, какими характеристиками атаки и механиками он должен обладать). 

2. **Зачем нужен super в конструкторе наследника? Что будет если его убрать?**

- Ключевое слово super вызывает конструктор родительского класса. Оно необходимо, чтобы передать обязательные базовые параметры (такие как name и hp) «наверх» для правильной инициализации полей базового класса.
- Если его убрать, возникнет ошибка компиляции, так как Dart не сможет автоматически инициализировать обязательные именованные параметры `(required this.name, required this.hp)` родительского класса Character.

3.**В чём разница между @override у attack() в Warrior и takeDamage() в Warrior? Почему второй переопределяет метод, который уже имеет реализацию в родителе?**

- Разница в том, что метод `attack()` в родителе является абстрактным (не имеет тела), и воину обязан дать ему первую реализацию, иначе проект не скомпилируется. Метод `takeDamage()` в родителе уже имеет готовую базовую логику.
- Воин переопределяет `takeDamage()`, чтобы изменить или расширить базовое поведение (добавить механику брони, уменьшающую входящий урон). При этом внутри новой логики он всё равно вызывает `super.takeDamage(reduced)`, делегируя финальное вычитание здоровья родительскому классу.

4. **Как называется концепция, когда функция fight() принимает базовый класс и не знает конкретного наследника? Где вы её видели во Flutter?**

- Эта концепция называется полиморфизмом.
- Во Flutter мы постоянно видим её в методе `Widget build(BuildContext context)`. Метод возвращает абстрактный тип Widget, но внутри него мы можем вернуть любого его конкретного наследника: Text, Column, Container, ElevatedButton и т.д.

5. **Что означает _random с нижним подчёркиванием в классе Character?**

- Нижнее подчёркивание перед именем `(_random)` в Dart означает, что это приватное поле `(private)`.
- Оно доступно для использования только внутри того файла (библиотеки), где оно объявлено, и скрыто от внешнего кода для соблюдения принципа инкапсуляции.
